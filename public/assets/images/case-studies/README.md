# Case Study Images

Store uploaded case study images in this folder, grouped by project slug:

- `/public/assets/images/case-studies/<study-slug>/hero.jpg`
- `/public/assets/images/case-studies/<study-slug>/gallery-1.jpg`
- `/public/assets/images/case-studies/<study-slug>/gallery-2.jpg`
- `/public/assets/images/case-studies/<study-slug>/detail-1.jpg`

Use lowercase slugs with hyphens so paths stay predictable in `src/data/koykoStudiesData.js`.
